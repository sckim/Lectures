# 📗 Digital_Logics 실습 예제

이 폴더는 디지털 논리 회로 및 시스템 설계를 위한 다양한 시뮬레이션 및 설계 툴 활용 예제들을 포함하고 있습니다. 각 툴의 특징에 맞춰 조합 논리 회로부터 복잡한 순차 회로까지 실습할 수 있습니다.

This folder contains examples of digital logic circuit and system design using various simulation and design tools.

---

## 🛠️ 실습 도구 및 예제 (Tools & Examples)

| 도구 (Tool) | 설명 (Description) | 예제 링크 (Example Link) |
| :--- | :--- | :--- |
| **Multisim** | 직관적인 GUI 기반의 아날로그/디지털 혼합 시뮬레이션 | [Multisim 예제](./Multisim/) |
| **Proteus** | MCU 연동 및 다양한 부품 시뮬레이션에 강점 | [Proteus 예제](./Proteus/) |
| **Quartus** | Intel FPGA 기반의 스키매틱 회로 설계 및 합성 | [Quartus 예제](./Quartus_schematics/) |
| **VHDL** | 하드웨어 기술 언어를 이용한 텍스트 기반 설계 | [VHDL 예제](./VHDL/) |
| **Simulink** | MATLAB 기반의 모델링 및 시스템 수준 시뮬레이션 | [Simulink 예제](./Simulink/) |

---

## 🔍 학습 안내 (Learning Guide)

1.  **초급 (1학기)**: `Multisim`과 `Quartus (Schematic)`를 통해 논리 게이트와 기본적인 조합/순차 회로의 동작을 익히는 것을 추천합니다.
2.  **중급 (2학기)**: `VHDL`을 사용하여 텍스트 기반의 설계를 배우고, `Simulink`를 통해 시스템 모델링을 실습합니다.
3.  **심화**: `Proteus`를 활용하여 마이크로컨트롤러와 주변 회로가 연동되는 전체 시스템을 시뮬레이션해 봅니다.
